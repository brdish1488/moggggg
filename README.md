# Лови круг — Circle Tap

Маленькая нативная игра для iPhone: 30 секунд, случайные круги, счёт и локальный рекорд. Без рекламы, сетевых запросов и сторонних библиотек. При сворачивании текущий раунд заканчивается.

## Сборка

Проект использует Swift и UIKit, без Godot/Unity. Код требует iOS 15+ и настоящий iPhone (arm64), не симулятор.

1. Загрузите все файлы в ветку `main`, включая `.github/workflows/build-ios.yml`.
2. Откройте вкладку **Actions → Build iPhone IPA**.
3. Сборка запускается при загрузке проекта; для повторного запуска используйте **Run workflow**.
4. После успешной сборки откройте запуск и скачайте **CircleTap-IPA** из раздела **Artifacts**. Распакуйте ZIP: внутри `CircleTap.ipa`.
5. Импортируйте IPA в уже настроенный LiveContainer.

Сборка использует стандартный `macos-15` runner. Не включайте платные larger runners. Для публичных репозиториев стандартные Actions runners бесплатны по текущим правилам GitHub. Артефакт автоматически удаляется через 3 дня — тогда можно повторить сборку.

IPA имеет только ad-hoc подпись: это НЕ App Store/TestFlight-сборка и не файл для обычной установки. Подпись и запуск внутри LiveContainer зависят от его версии, настроек и версии iOS. Совместимость нужно проверить на устройстве. Apple ID, сертификаты и секреты этому workflow не нужны.

Исходники подготовлены в Linux; компиляция Swift/UIKit и запуск на устройстве ещё не проверены. Первый успешный запуск Actions проверит сборку.
